# Markdown 常用语法速查

Markdown 使用简单的文本符号来设置格式。下面汇总日常写作中常用的语法及示例。

## 1. 标题

使用 `#` 表示标题级别，支持一级到六级标题。`#` 后需加空格。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 段落与换行

- **新段落**：两段文字之间留一个空行。
- **段内换行**：在行末添加两个空格再回车，或使用 `<br>`（需要渲染器支持 HTML）。
- 只按一次回车，在许多渲染器中不会显示为换行。

```markdown
这是第一段。

这是第二段。
```

## 3. 文字格式

| 格式 | 语法 | 效果 |
| --- | --- | --- |
| 加粗 | `**文字**` | **文字** |
| 斜体 | `*文字*` | *文字* |
| 加粗斜体 | `***文字***` | ***文字*** |
| 删除线（扩展语法） | `~~文字~~` | ~~文字~~ |
| 行内代码 | `` `代码` `` | `代码` |

## 4. 列表

### 无序列表

使用 `-`、`*` 或 `+`，符号后加空格。

```markdown
- 苹果
- 香蕉
- 橙子
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 嵌套列表

子项需缩进；使用四个空格通常更稳妥。

```markdown
- 学习计划
    - Markdown
    - Python
- 工作计划
    1. 整理资料
    2. 完成报告
```

### 任务列表（扩展语法）

```markdown
- [ ] 待完成任务
- [x] 已完成任务
```

## 5. 引用

使用 `>`；连续引用可在每行前添加该符号。

```markdown
> 这是一段引用。
>
> 这是引用中的另一个段落。
>> 这是嵌套引用。
```

## 6. 代码

### 行内代码

```markdown
使用 `print()` 输出内容。
```

### 代码块

使用三个反引号包围代码，开头可指定语言以启用语法高亮。

````markdown
```python
print("Hello, Markdown!")
```
````

若代码内容本身含有三个反引号，可在外层使用四个反引号。

## 7. 链接

### 普通链接

```markdown
[显示文字](https://example.com)
[带提示的链接](https://example.com "鼠标悬停提示")
```

### 引用式链接

适合在文档中多次使用同一个链接。

```markdown
查看[示例网站][site]。

[site]: https://example.com "示例网站"
```

### 自动链接

```markdown
<https://example.com>
<name@example.com>
```

### 相对路径链接

```markdown
[阅读说明](./README.md)
[打开资料](./资料/说明.md)
```

相对路径通常以当前 Markdown 文件所在目录为起点，具体行为取决于平台。

## 8. 图片

图片语法比链接多一个 `!`。方括号中的文字是替代文本，用于图片无法显示时及无障碍阅读。

```markdown
![图片说明](https://example.com/image.png)
![本地图片](./images/photo.png)
![带提示的图片](./images/photo.png "图片标题")
```

标准 Markdown 不提供通用的图片尺寸设置语法；部分平台支持 HTML 或自定义扩展。

## 9. 分隔线

单独一行使用三个或更多的 `-`、`*` 或 `_`，前后留空行更清晰。

```markdown
上面的内容。

---

下面的内容。
```

## 10. 表格（扩展语法）

使用 `|` 分隔列，使用 `-` 分隔表头与内容。冒号用于设置对齐方式。

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 苹果 | 10 个 | 20 元 |
| 香蕉 | 5 个 | 15 元 |
```

在表格单元格中显示竖线时，可使用 `\|` 转义。

## 11. 转义特殊字符

在符号前加反斜杠 `\`，可让它显示为普通字符。

```markdown
\*这段文字不会变成斜体\*
\# 这行不会变成标题
\[这不是链接\]
```

常见可转义符号包括：`*`、`_`、`#`、`[`、`]`、`(`、`)`、`!`、`|` 和反引号。

## 12. 常见平台扩展

以下写法不是所有 Markdown 渲染器都支持，使用前应检查目标平台。

### 脚注

```markdown
这是一段带脚注的文字。[^1]

[^1]: 这里是脚注内容。
```

### 数学公式

部分平台支持 LaTeX 公式。

```markdown
行内公式：$E = mc^2$

独立公式：
$$
a^2 + b^2 = c^2
$$
```

### 折叠内容

需要平台允许对应 HTML 标签。

```html
<details>
<summary>点击展开</summary>

这里是折叠内容。

</details>
```

### 注释

支持 HTML 注释的渲染器通常不会在预览中显示这段内容，但它仍保留在源文件中。

```markdown
<!-- 这里是注释 -->
```

## 13. 综合示例

````markdown
# 项目笔记

## 今日计划

- [x] 整理资料
- [ ] 编写文档

> 提醒：保存后检查预览效果。

重点内容用 **加粗**，命令用 `git status`。

查看[项目说明](./README.md)。

```python
print("开始学习 Markdown")
```

| 任务 | 状态 |
| --- | --- |
| 整理资料 | 已完成 |
| 编写文档 | 进行中 |

---

最后更新：2026-10-08
````

## 使用建议

- 标题、列表、代码块前后适当留空行，提升可读性与兼容性。
- 标题符号、列表符号与正文之间加空格。
- 列表缩进使用空格，并保持一致。
- 编辑后检查预览；表格、任务列表、删除线、公式等扩展的支持情况因平台而异。
- Markdown 是标记语法，各编辑器的快捷键可能不同。
