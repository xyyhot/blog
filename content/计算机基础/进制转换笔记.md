# 进制转换笔记

## 一、整数进制转换

### 1. 进制的含义

几进制就是“逢几进一”。

- 二进制：使用 `0、1`。
- 八进制：使用 `0～7`。
- 十进制：使用 `0～9`。
- 十六进制：使用 `0～9、A～F`，其中 `A～F` 分别代表 `10～15`。

### 2. 其他进制 → 十进制

方法：每一位乘以对应的位权，再相加。从右往左，位权依次是进制的 0、1、2……次方。

**口诀：从右起，次方从零数。**

例：二进制 `1011` 转成十进制。

```text
1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
      = 8 + 0 + 2 + 1
      = 11₁₀
```

### 3. 十进制整数 → 其他进制

方法：反复除以目标进制，记录余数，商到 0 就停止，余数从下往上读。

**口诀：除以目标进制，余数倒着读。**

例：十进制 `168` 转成二进制。

| 运算 | 商 | 余数 |
|---|---:|---:|
| 168 ÷ 2 | 84 | 0 |
| 84 ÷ 2 | 42 | 0 |
| 42 ÷ 2 | 21 | 0 |
| 21 ÷ 2 | 10 | 1 |
| 10 ÷ 2 | 5 | 0 |
| 5 ÷ 2 | 2 | 1 |
| 2 ÷ 2 | 1 | 0 |
| 1 ÷ 2 | 0 | 1 |

余数从下往上读：`10101000`。

```text
168₁₀ = 10101000₂
```

反向检查：`128 + 32 + 8 = 168`。

### 4. 二进制 ↔ 八进制、十六进制

因为 `8 = 2³`、`16 = 2⁴`，可以分组转换。

- 二进制转八进制：从右往左，每 3 位一组。
- 二进制转十六进制：从右往左，每 4 位一组。
- 最左边不够位时，在左边补零。
- 反向转换时，每一位八进制数换成 3 位二进制数，每一位十六进制数换成 4 位二进制数。
- 小数点左边缺位左补零，右边缺位右补零。

例：二进制 `110101`。

```text
转八进制：110 101 → 6 5 → 65₈
转十六进制：0011 0101 → 3 5 → 35₁₆
```

## 二、小数进制转换

### 1. 十进制小数 → 二进制

方法：每次乘以 2，取出整数部分，再用剩下的小数继续乘，直到小数部分变成 0。

**口诀：小数乘二，整数顺读。**

例：十进制 `0.625` 转成二进制。

| 运算 | 取出的整数部分 | 剩下的小数 |
|---|---:|---:|
| 0.625 × 2 = 1.25 | 1 | 0.25 |
| 0.25 × 2 = 0.5 | 0 | 0.5 |
| 0.5 × 2 = 1.0 | 1 | 0 |

取出的整数部分从上往下读：`101`，写在小数点右边。

```text
0.625₁₀ = 0.101₂
```

转成其他进制时，把 2 换成目标进制。转十六进制时，取出的整数若是 10～15，要写成 A～F。

### 2. 二进制小数 → 十进制

方法：每一位乘以对应的位权，再相加。

小数点右边，从左往右的位权依次是：

```text
2⁻¹ = 1/2
2⁻² = 1/4
2⁻³ = 1/8
……
```

例：

```text
0.101₂ = 1×(1/2) + 0×(1/4) + 1×(1/8)
       = 0.5 + 0 + 0.125
       = 0.625₁₀
```

其他进制的小数也用同样的方法，把位权的底数换成该进制即可。

### 3. 同时含有整数和小数的数

整数部分和小数部分分开转换，再用小数点拼起来。

```text
168₁₀ = 10101000₂
0.625₁₀ = 0.101₂

所以：168.625₁₀ = 10101000.101₂
```

**总口诀：整数除二，余数倒读；小数乘二，整数顺读。**

### 4. 无限循环与精度

并非每个有限的十进制小数都能转成有限的二进制小数。例如 `0.1₁₀` 转成二进制会无限循环。

遇到这种情况，要按题目要求保留一定的位数，并注意题目要求的是截断还是舍入。有限位数的结果通常是近似值，应使用 `≈`。
