## 一、Vim 的三种常用模式

| 模式 | 作用 | 进入方式 |
|---|---|---|
| 普通模式（Normal） | 移动、复制、删除、保存等 | 按 `Esc` |
| 插入模式（Insert） | 输入文字 | 普通模式下按 `i`、`a`、`o` 等 |
| 命令模式（Command） | 执行保存、退出、查找替换等命令 | 普通模式下按 `:` |

> 刚打开 Vim 时通常处于普通模式。按 `i` 开始输入，按 `Esc` 回到普通模式。

## 二、打开与退出

| 按键或命令 | 作用 |
|---|---|
| `vim 文件名` | 打开文件 |
| `:w` | 保存文件 |
| `:q` | 退出 Vim |
| `:wq` | 保存并退出 |
| `:x` | 保存并退出 |
| `:q!` | 不保存，强制退出 |
| `ZZ` | 保存并退出（普通模式） |
| `ZQ` | 不保存并退出（普通模式） |

## 三、进入插入模式

| 按键 | 作用 |
|---|---|
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `I` | 在当前行开头插入 |
| `A` | 在当前行末尾插入 |
| `o` | 在当前行下方新建一行并插入 |
| `O` | 在当前行上方新建一行并插入 |
| `Esc` | 返回普通模式 |

## 四、光标移动

### 基础移动

| 按键 | 作用 |
|---|---|
| `h` | 向左 |
| `j` | 向下 |
| `k` | 向上 |
| `l` | 向右 |
| `0` | 移到行首 |
| `^` | 移到行首第一个非空字符 |
| `$` | 移到行尾 |
| `gg` | 移到文件开头 |
| `G` | 移到文件末尾 |
| `nG` | 移到第 `n` 行，例如 `10G` |
| `Ctrl + f` | 向下翻一页 |
| `Ctrl + b` | 向上翻一页 |
| `Ctrl + d` | 向下翻半页 |
| `Ctrl + u` | 向上翻半页 |

### 按单词移动

| 按键 | 作用 |
|---|---|
| `w` | 移到下一个单词开头 |
| `b` | 移到上一个单词开头 |
| `e` | 移到当前或下一个单词末尾 |

## 五、删除、复制与粘贴

| 按键 | 作用 |
|---|---|
| `x` | 删除当前字符 |
| `dd` | 删除当前行 |
| `ndd` | 删除 `n` 行，例如 `3dd` |
| `dw` | 删除当前单词到下一个单词开头 |
| `D` | 删除光标到行尾的内容 |
| `yy` | 复制当前行 |
| `nyy` | 复制 `n` 行，例如 `3yy` |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |
| `u` | 撤销 |
| `Ctrl + r` | 重做 |
| `.` | 重复上一次修改 |

## 六、查找与替换

| 按键或命令 | 作用 |
|---|---|
| `/关键词` | 向下查找关键词 |
| `?关键词` | 向上查找关键词 |
| `n` | 查找下一个 |
| `N` | 查找上一个 |
| `:%s/旧内容/新内容/g` | 全文替换 |
| `:n,m s/旧内容/新内容/g` | 替换第 `n` 到 `m` 行 |

## 七、选择与缩进

| 按键 | 作用 |
|---|---|
| `v` | 按字符选择 |
| `V` | 按行选择 |
| `Ctrl + v` | 按列块选择 |
| `>` | 增加缩进 |
| `<` | 减少缩进 |
| `=` | 自动缩进 |
| `gg=G` | 整个文件自动缩进 |

## 八、常用命令

| 命令 | 作用 |
|---|---|
| `:set number` | 显示行号 |
| `:set nonumber` | 隐藏行号 |
| `:set relativenumber` | 显示相对行号 |
| `:e 文件名` | 打开另一个文件 |
| `:sp 文件名` | 水平分屏打开文件 |
| `:vs 文件名` | 垂直分屏打开文件 |
| `Ctrl + w + h/j/k/l` | 在分屏之间移动 |
| `:help 命令` | 查看帮助，例如 `:help dd` |

## 九、最常用操作流程

```text
1. vim 文件名       打开文件
2. i                 进入插入模式
3. 输入或修改内容
4. Esc               回到普通模式
5. :w                保存
6. :q                退出
```

## 十、记忆口诀

- `i` 插入，`a` 追加，`o` 新开一行。
- `h j k l` 分别是左、下、上、右。
- `d` 删除，`y` 复制，`p` 粘贴。
- `u` 撤销，`Ctrl + r` 重做。
- `:w` 保存，`:q` 退出，`:wq` 保存并退出。
