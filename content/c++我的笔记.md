# 第一部分 · 基础语法

## 一、程序基本功

- `return 0;` 在 `main()` 中结束程序；**注意**：`return` 也可以结束函数，不一定只能结束程序
- 变量如果在花括号内创建，只有花括号内的语句知道这个变量

### 局部变量和全局变量的区别

把 `day` 放在外面作为全局变量，最致命的影响是**每次调用函数时数据不会清零，导致天数发生“滚雪球”式的无限累加**。当你把它定义在全局（函数外部）时，它的生命周期贯穿整个程序。

> **核心结论**：像“累加器（`sum`、`day`、`count` 等）”这种只为单次计算服务的数据，**必须写在函数内部**。这样每次进入函数时，内存都会给它重新分配空间并初始化为 `0`，保证每次计算都是干净、独立的。

### cin 规则

## 三、数据类型

### int 与 long long

- ==`int` 范围约 ±1e9==；超过就用 `long long`
- 竞赛建议：涉及**前缀和、乘法、大数字**时优先开 `long long`

- 存在小数的任何计算（含中间结果）都要 `double`

- `1.23e4 = 12300`，`5.67E-3 = 0.00567`
- 规则：`e` 前必须有数字；`e` 后必须是整数（可带 ±）
- 默认 `double`；加 `f` → `float`；加 `l` → `long double`

## 四、数位处理

### 数位和的递推

任意非负整数 `i` 的数位和，等于去掉最后一位后的数 `i / 10` 的数位和，加上最后一位 `i % 10`：

```cpp
s[i] = s[i / 10] + i % 10;
```

预处理后每个位置都能在 `O(1)` 时间得到数位和。

| 目标 | 写法 |
| --- | --- |
| 个位 | `n % 10` |
| 十位 | `n / 10 % 10` |
| 四位数 · 千位 | `n / 1000` |
| 四位数 · 百位 | `(n % 1000) / 100` |
| 四位数 · 十位 | `n % 100 / 10` |
| 四位数 · 个位 | `n % 10` |

> **规律**：只要后面一位 `/ 10` 再 `% 10`。

反向输出：

```cpp
while (n) { cout << n % 10; n /= 10; }
```

把所有的数位全反过来（数字反转）：

```cpp
while (n) s = s * 10 + n % 10, n /= 10;
```

### 埃氏筛（求 1~n 所有质数，O(n log log n)）

需要“一次判断多个数是否为质数”时，用筛法预处理好，判断变 O(1)。

```cpp
const int maxn = 1e6 + 10;   // 题目的数字最大值
vector<bool> pri(maxn);      // 防止越界，0 为素数，1 为合数（被筛），判断是否是质数

int main() {
    int n = 1e6, cnt = 0;    // 题目的数字最大值，质数的个数

    // 枚举到 √n 即可。为什么？因为一个合数 x 一定存在一个不超过 x 的质因子。
    for (int i = 2; i <= n / i; i++) {
        if (!pri[i]) {                       // i 是质数 → 筛掉它的倍数
            for (int j = i * i; j <= n; j += i) pri[j] = 1;
        }
    }

    for (int i = 2; i <= n / i; i++) if (!pri[i]) cnt++;   // 计算质数的个数
    // isPrime[x] == true ⇔ x 是质数（x ∈ [2, n]）
}
```

- 关键点：内层从 `i*i` 开始，`i*i` 之前的最小因子在更小 i 时已被筛掉，避免重复标记
- 复杂度 O(n log log n)，n=1e7 也能秒过；判断单个大数仍用上面的试除法

### 线性筛（欧拉筛，O(n)）

埃氏筛的优化版：每个合数**只被它的最小质因子筛一次**，达到严格 O(n)。

```cpp
const int maxn = 1e7 + 10;   // 题目的数字最大值
vector<bool> pri(maxn);      // 防止越界，0 为素数，1 为合数（被筛），判断是否是质数
int primes[maxn], pp = 0;    // pp 为第几个质数

int main() {
    int n = 1e7, cnt = 0;    // 题目的数字最大值，质数的个数

    for (int i = 2; i <= n; i++) {       // 枚举到 n，与上面不同
        if (!pri[i]) primes[pp++] = i, cnt++;
        for (int j = 1; primes[j] * i <= n; j++) {
            pri[primes[j] * i] = 1;
            // key：i 负责提供“被乘的部分”，primes[j] 负责提供“最小质因子”，
            // 一旦 primes[j] 是 i 的最小质因子，就停止。
            if (i % primes[j] == 0) break;
        }
    }
}
```

> **关键点**：`if (i % primes[j] == 0) break;` —— 当 `primes[j]` 是 `i` 的质因子时立即停止，保证合数只会被它**最小的质因子**筛掉，不重复，复杂度才是 O(n)。
>
> **区别**：埃氏筛 O(n log log n)、代码简单；线性筛 O(n)、略复杂，n 很大且需最小质因子（如质因数分解）时用线性筛更稳。
>
> - 埃氏筛是：**枚举质数 p，然后删掉 p 的所有倍数。**
> - 欧拉筛是：**枚举每个数 i，让 i 和已有质数结合，生成合数，并保证每个合数只被筛一次。**

## 九、数组、vector 与 set

### 数组

- 在大多数表达式中，数组名会自动退化为指向首元素的指针；例如把数组传给函数时通常只传递首地址，因此不会完整复制一份数组。`sizeof`、`&数组` 等场景不会发生退化。

## 十一、取模

- 加法满足**交换律、结合律**：`(a+b)%m` 可拆为 `(a%m + b%m)%m`，多次取模结果相同
- 常见写法：`ans = (ans * i) % 1000000007;`

求给你的秒数共有多少小时（小时 < 24）：

```cpp
int h = (t % 86400) / 3600;   // 86400 = 24 * 3600
int m = (t % 3600) / 60;
int s = t % 60;
```

- **`s = t % 60`**：去除能整除整分钟的秒数，剩下的即为不足 1 分钟的秒（范围：`0` ~ `59`）
- **`m = (t % 3600) / 60`**：`t % 3600` 滤掉完整的整小时，剩下的总秒数除以 `60` 得到分钟（范围：`0` ~ `59`）
- **`h = (t % 86400) / 3600`**：`t % 86400` 滤掉整天（一昼夜 24 小时 = 86400 秒），剩下的总秒数除以 `3600` 得到当天的小时数（范围：`0` ~ `23`）。如果你的场景**不需要按 24 小时循环**（例如计时器累积超过一天仍想输出 `25小时`），则去掉 `% 86400`，直接写 `h = t / 3600;`

## 十二、数学技巧

- **循环移位**：只用 `%`，如 `(i + k) % n`，不要手动推加减
- 等差数列求和：`Sn = n * (a1 + an) / 2 = n * (n+1) / 2`
- `sqrt(n)` 返回 **double**（int 参数也返回 double）

## 十六、sscanf 的用法

`sscanf` 可以简单理解成：

> **从一个字符串里，按照指定格式，把里面的数据“拆出来”。**

它和你可能学过的 `cin` 很像，只不过 `cin` 是从键盘输入读取，`sscanf` 是从**字符串**里读取。

### 先看一个最简单的例子

```cpp
string s = "123 456";

int a, b;

sscanf(s.c_str(), "%d %d", &a, &b);
```

执行之后：

```cpp
a = 123;
b = 456;
```

也就是说：

```text
字符串 "123 456"
    ↓
 sscanf
    ↓
a = 123
b = 456
```

### 为什么要写 `s.c_str()`？

因为 `s` 是 C++ 的 `string`，而 `sscanf` 要求传入的是 C 风格字符串。

所以 `s.c_str()` 就是把 `string` 转成 `sscanf` 能处理的形式。你现在可以暂时记成：

```cpp
sscanf(s.c_str(), ...)
```

就是：

> “从字符串 `s` 里面读取数据”。

`%d` 表示：

> 按照 `int` 类型读取一个整数

**字符**，应该使用 `%c`。

## 二十八、if 和 else if 的区别

- **多个独立的 `if`**：每一个 `if` 的条件都会被**无条件执行和判断**。如果多个条件同时满足，它们内部的代码都会执行。
- **`if...else if...else`**：条件是互斥（排他）的。程序从上往下判断，**一旦某个条件成立，执行对应代码块后会直接跳过整条链剩余的所有判断**。

## 三十一、向上、向下取整

我们可以想一下，什么情况下我们要向上取整加一，其实就是在 s 不能被 t 整除的时候，那么我们只需要排除整除的情况加一即可，所以我们在整除的时候对 s 加上一个 t-1，因为 t-1 被 t 整除为 0，这就能保证如果 s 本来是被 t 整除的时候，加上 t-1 也不会使其结果加上 1，而任意不能被整除的都能使结果加一。

```cpp
(s + t - 1) / t;   // 向上取整
```

向下取整你懂的。

## 三十二、scanf 与 printf 常规用法

> 需要 `#include <cstdio>`；和“十五、如何在给定的数字前面加东西（补前导 0）”“十六、sscanf 的用法”“十七、C 语言中的数据格式”配套看。

### printf

```cpp
printf("格式串", 参数...);
printf("%d\n", x);        // 最普通的一行
```

| 要输出的类型 | printf |
| --- | --- |
| int | `%d`（`%i` 等价） |
| long long | `%lld`（写成 `%d` 会输出乱码） |
| unsigned | `%u` |
| float / double | `%f`（float 会自动提升为 double） |
| long double | `%Lf` |
| char | `%c` |
| char[] / `s.c_str()` | `%s` |
| 十六进制 | `%x` / `%X`（小写 / 大写） |
| 八进制 | `%o` |
| 指针 | `%p` |
| 百分号本身 | `%%` |

**宽度、精度、对齐**

```cpp
printf("%5d|\n", 42);       // "   42|"  右对齐，宽度 5，不足补空格
printf("%-5d|\n", 42);      // "42   |"  左对齐
printf("%05d\n", 42);       // "00042"   补前导 0
printf("%.2f\n", 3.14159);  // "3.14"    保留两位，自动四舍五入
printf("%8.3f\n", 3.14159); // "   3.142"
printf("%.3s\n", "abcdef"); // "abc"     只输出前 3 个字符
printf("%x %o %%\n", 255, 8);   // "ff 10 %"
```

**动态宽度 / 精度**（宽度、小数位数由参数给，排版省事）

```cpp
printf("%*d\n", w, x);      // 宽度取 w
printf("%.*f\n", k, x);     // 小数位数取 k
```

- `printf` 是行缓冲，**不写 `\n` 有时看不到输出**；本地调试卡住时补个 `\n` 或 `fflush(stdout);`
- 输出 `-0.00` 是常见 WA：`if (fabs(x) < 1e-9) x = 0;`
- 返回值是实际输出的字符个数，一般用不上

### scanf

```cpp
scanf("格式串", &变量...);   // 除 char 数组外都要写 &
```

| 类型 | scanf | printf |
| --- | --- | --- |
| int | `%d` | `%d` |
| long long | `%lld` | `%lld` |
| float | `%f` | `%f` |
| **double** | **`%lf`** | **`%f`** |
| long double | `%Lf` | `%Lf` |
| char | `%c` | `%c` |
| char 数组 | `%s` | `%s` |

> 记法：**scanf 读 double 必须 `%lf`**（float 才用 `%f`），printf 里 `%f` 就够。读 double 用 `%f` 是经典事故，读出来是 0 或垃圾值。

```cpp
int a, b;
scanf("%d%d", &a, &b);        // 输入 "10 20" 或 "10\n20" 都行

char s[100];
scanf("%s", s);               // 数组名即地址，不用 &；遇空白停止
scanf("%10s", s);             // 限长，防止越界

char c;
scanf(" %c", &c);             // 注意 %c 前面这个空格

double d;
scanf("%lf", &d);

int x, y;
scanf("%d %*d %d", &x, &y);   // %* 表示读入但不保存："1 2 3" → x=1, y=3
```

**格式串里的空白与普通字符**

- 空白（空格、换行）表示“**跳过任意多个空白**”，所以 `"%d%d"` 和 `"%d %d"` 读数字时完全等价
- 非空白字符必须原样输入：`scanf("%d,%d", &a, &b);` 要求输入 `3,5`，输入 `3 5` 会失败

**多组 / 未知数量输入**

```cpp
int n;
while (scanf("%d", &n) != EOF) { /* ... */ }   // 读到文件结束
while (scanf("%d", &n) == 1)   { /* ... */ }   // 成功读满 1 个变量
```

`scanf` 的返回值 = **成功读入的变量个数**，读到结尾返回 `EOF`（就是 -1）。输入数量不定、多测的题都靠它。

**读整行 / 处理字符流**

- `%s` 读不到空格；读整行用 `scanf("%[^\n]", buf)`，或 `fgets` / C++ 的 `getline`
- 吞掉一个字符（比如换行）用 `getchar();`
- `sscanf(str, "%d", &x)` 的格式串与 `scanf` **完全一样**，只是从字符串里读（见“十六”那节）；反过来 `sprintf(buf, "%d", x)` 是把 printf 写进字符串

### 踩坑清单

1. **忘了 `&`**：读 int / char / double 都要 `&`，只有 char 数组不用
2. **`%c` 读到空格/换行**：`scanf("%c", &c)` 常常读到上一个数后面的换行 → 写成 `scanf(" %c", &c)`，或改用 `cin >> c`
3. **格式串末尾加 `\n`**：`scanf("%d\n", &x)` 会让程序等你多输入一个非空白字符才继续，是个经典卡死坑
4. **类型配错格式符**：`long long` 配 `%d`、读 `double` 配 `%f`，都会得到垃圾值
5. **`%s` 越界**：`%s` 不检查长度，题目字符串很长时会炸，要限长或用 `cin >> s`（string 会自动扩容）
6. **混用 cin/cout**：如果写了 `ios::sync_with_stdio(false)`，就**别再混用 `scanf/printf`**，顺序会乱；默认不关同步时能混但慢
7. **规模取舍**（见“七、TLE”）：规模 **> 1e5** 就把 `cin/cout` 换成 `scanf/printf`；要更快再上 `getchar` 快读
8. **答案每次都不一样" = 未定义行为的红旗，不是算法随机。** 一看到结果不稳定，第一反应应该是**越界 / 未初始化 / 读到脏内存**，

        printf("%05d %.2f%%\n", n, n * 100.0 / 1000);

## 3. DFS 详细

### 三类题型

都是多叉树搜索，区别只在**每层候选怎么选**：

| 题型 | 每层候选 | 去重方式 | 例子 |
| --- | --- | --- | --- |
| **元组** | 全部元素，可重复选 | 无 | 从 n 个字母中取 k 个（可重复） |
| **排列** | 全部元素，不能重复选 | used 数组 | 1~n 的全排列 |
| **组合** | 只能选比上一层“更大的” | 循环从 start 开始 | 从 n 个数中取 k 个（顺序无关） |

**关键区别一句话**：

- 元组：`for (int i = 1; i <= n; i++)`，不标记 → 可重复
- 排列：`for (int i = 1; i <= n; i++)` + `used[i]` → 不可重复
- 组合：`for (int i = start; i <= n; i++)` → 只往后走，避免重复组合

### 三类模板对比

```cpp
// 元组：每层都能选全部（如 k 位密码）
void dfs(int step) {
    if (step > k) { 处理答案; return; }
    for (int i = 1; i <= n; i++) {   // 不限制、不标记
        a[step] = i;
        dfs(step + 1);
    }
}

// 排列：每层排除已用的
void dfs(int step) {
    if (step > k) {
        处理答案;
        return;              // 结束本次循环
    }
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {      // 没用过才往下走
            used[i] = 1;
            a[step] = i;
            dfs(step + 1);
            used[i] = 0;     // 回溯撤销
        }
    }
}

// 组合：只能往“后面”选，保证不重复（如 C(n,k)）
void dfs(int step, int start) {
    if (step > k) {
        处理答案;
        return;
    }
    for (int i = start; i <= n; i++) {
        a[step] = i;
        dfs(step + 1, i + 1);        // 从 i+1 开始，只能选更大的
    }
}
```

### 核心思想（回溯）

```text
选择 → 进入下一层 → 撤销选择
```

进入下一层 = 调用函数；返回上一层 = 函数结束或 `return`，然后继续执行调用位置后面的代码。

有的时候剪枝和回溯可以换的，二选一。

### 模板

```cpp
void dfs(状态参数) {
    if (满足终止条件) { 处理答案; return; }
    if (不合法) return;              // 剪枝（可选）
    for (每个候选方案) {
        if (非法/已用) continue;     // 跳过
        标记状态;                    // 尝试
        dfs(下一状态);               // 深入
        撤销标记;                    // 回溯恢复现场
    }
}
```

### 排列实例

```cpp
int n, k;
vector<int> a(50), used(50);

void dfs(int step) {
    if (step == k + 1) {                       // ① 终止
        for (int i = 1; i <= k; i++) cout << a[i] << " ";
        cout << endl;
        return;
    }
    for (int i = 1; i <= n; i++) {             // ② 枚举候选
        if (used[i] == 1) continue;
        used[i] = 1;                           // ③ 标记
        a[step] = i;
        dfs(step + 1);                         // ④ 递归
        used[i] = 0;                           // ⑤ 回溯
    }
}
```

### 枚举型（字典序）

```cpp
string ans;

void dfs(int step) {
    if (step == n + 1) { cout << ans << "\n"; return; }
    ans.push_back('N'); dfs(step + 1); ans.pop_back();
    ans.push_back('Y'); dfs(step + 1); ans.pop_back();
}
```

## 4. BFS（广度优先搜索）

- 与 DFS 相对：DFS 一路走到底再回头，BFS **一层一层向外扩散**
- 特点：第一次到达某点时的步数，就是**最短步数**（无权重图）
- 用 `queue` 实现：入队 → 逐层取出 → 扩展邻居
- 方法：写题之前画一个树状图

### 模板（求最短路步数）

```cpp
#include <queue>
const int N = 105;
int vis[N];                       // 访问标记，防止重复入队
int dist[N];                      // 起点到每个点的最短步数

int bfs(int start, int goal) {
    queue<int> q;
    q.push(start);
    vis[start] = 1;
    dist[start] = 0;
    while (!q.empty()) {
        int x = q.front(); q.pop();
        if (x == goal) return dist[x];       // 到达终点，返回步数
        for (int nx : 每个邻居) {             // 扩展
            if (vis[nx]) continue;           // 已访问则跳过
            vis[nx] = 1;
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }
    }
    return -1;                               // 无法到达
}
```

### 与 DFS 对比

|  | DFS | BFS |
| --- | --- | --- |
| 结构 | 递归 + 回溯 | 队列 + 逐层扩散 |
| 适用 | 枚举方案、连通性、回溯 | 最短路、最少步数 |
| 标记时机 | 进入前标记，回溯时撤销 | 入队即标记，**不撤销** |
| 代码量 | 少 | 略多（需要队列） |

> 提醒：BFS 中每个点**入队时就要标记**，否则会重复入队导致死循环或 MLE；与 DFS 的“回溯撤销”完全相反。

## 5. 前缀和（洛谷 B3612）
“统计有多少个连续子数组/区间，满足区间和恰好等于 K”
连续区间 + 恰好多少个
- 预处理：`s[i] = s[i-1] + a[i];`
- 区间和：`sum(l, r) = s[r] - s[l-1]`
- 复杂度：预处理 O(n)，查询 O(1)；暴力每次 O(n)，询问多会超时
- 题面要求统计**连续子数组/区间**的数量。
    
- 条件涉及区间的和、差、奇偶性、模数或特定字符出现次数（例如“0和1数量相等的子串”：将 0 视为 -1，转化为前缀和为 0 的区间统计）。
    
- 题目只问**区间总数**，而不要求输出具体区间方案。

## 7. TLE（超时）

程序能跑但太慢，超过时限。**判断标准：算法复杂度 × 数据规模**，先看 n 再定算法。

| 复杂度 | 能承受的 n |
| --- | --- |
| O(n) / O(n log n) | ~10^6 ~ 10^7 ✅ |
| O(n²) | ~10^3 ~ 10^4 ⚠️ |
| O(n³) | ~10^2 ~ 10^3 ❌ |
| O(2ⁿ) / O(n!) | ~20 ~ 10 ❌❌ |

2 的幂速记：

- 2 的十次方等于 1024
- 2 的二十次方等于 10 的 6 次方
- 2 的 31 次方等于 2 * 10 的九次方
- 2 的 64 次方等于 1e18

### 常见原因

1. **复杂度过高**：n=10^5 用 O(n²) 必死
2. **死循环**：`while(l<r)` 忘记移动 l/r；`for(i=0;i<n;i--)`
3. **重复计算**：多次区间和应前缀和 O(n+m)，别每次重算 O(n·m)
4. **IO 太慢**：大数据用 `'\n'` 别用 `endl`，加 `ios::sync_with_stdio(0)`
5. **递归无记忆化**：朴素斐波那契 O(2ⁿ)，DP / 记忆化 O(n)
6. **STL 不当**：大且频繁访问用哈希表代替 map/set；少用 `s.substr()`

### 排查套路

1. 算复杂度，看循环层数和 n 是否匹配
2. 本地造 n=10^6 的最大数据测耗时
3. 检查二分 / while 更新条件是否死循环
4. 优化 IO：`ios::sync_with_stdio(0); cin.tie(0);` 或快读
5. 换算法：O(n²) → 前缀和 / DP / 双指针 / 二分
6. 当数据范围大于 1e5 时候，替换 cin cout 为 scanf printf

### 降复杂度对照

| 场景 | 朴素 | 优化 |
| --- | --- | --- |
| 多次区间和 | O(n·m) | 前缀和 O(n+m) |
| 有序查找 | O(n) | 二分 O(log n) |
| 斐波那契 | O(2ⁿ) | DP O(n) |
| 两数之和 | O(n²) | 哈希表 O(n) |
| 最大子段和 | O(n²) | DP O(n) |

> TLE = **太慢**。90% 是“复杂度和数据规模不匹配”。

## 10. 差分

**差分是前缀和的逆运算。前缀和擅长“区间求和”，差分擅长“区间整体加同一个数”。**

差分通过前缀和还原成原数组，先修完，再查询。

```cpp
const int MAXN = 100000 + 5;
int d[MAXN + 2];                    // 多开 2 格，防 r+1 越界

// 操作：区间 [l, r] 里每个元素 += v                     —— O(1)
// 原因：做前缀和的时候后面的数都会加上这个数导致 +1，同理减也都会减 1
void add(int l, int r, int v) {
    d[l]     += v;
    d[r + 1] -= v;
}

// 收尾：所有操作登记完后，做一次前缀和还原               —— O(n)
for (int i = 1; i <= n; i++) d[i] += d[i - 1];
// 此刻 d[i] 就是第 i 个位置的最终真实值
```

|     | 前缀和              | 差分                |
| --- | ---------------- | ----------------- |
| 擅长  | **多次区间求和**，一次预处理 | **多次区间修改**，一次收尾查询 |
| 修改  | 慢（O(n)）          | 快（O(1)）           |
| 查询  | 快（O(1)）          | 慢（要 O(n) 还原）      |
|     |                  |                   |

题目里出现"**对相邻元素做同一种 ±1 操作**"，几乎都可以往差值数组上转化：

- 区间加 1 / 区间修改类 → **差分数组**（相邻操作变成单点操作）；
- 本题"相邻两数同时 ±1，要求回文" → **镜像差值数组**：`d_i = a_i − a_{n+1−i}`（本题写成了"需求 `b`"）。此时
    - 作用于左半边相邻两位置 → 给**相邻两个 `d` 同时 ±1**；
    - 作用于跨越中线的那一对 → 对 `d` **毫无影响**（白费）；
    - 作用于单个元素（含奇数中间元素） → 给**单个 `d` ±1**。

## 11.双指针
双指针不是一个具体算法，而是**一种"用两个下标扫数组"的写法**。核心只有一句话：**两个指针都只朝一个方向走，绝不回头**，所以总共最多走 2n 步 —— 把 O(n²) 的双重循环压成 O(n)。
例如
`int main(){`
	`ll ans=0;`
	`ll j=0;`
	`cin>>a>>b;`
	`for(int i=0;i<a.size();i++)`
	`{`
		`if(a[i]==b[j]){`
			`ans++;`
			`j++;`
		`}`
	`}`
	`cout<<ans;`
	`return 0;`
`}`
